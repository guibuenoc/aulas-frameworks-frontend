# Aula 05 - Criando APIs para o Front-end

## Introdução

Nesta aula foi estudada a criação de uma API utilizando Node.js e Express. O objetivo foi entender melhor como funciona a comunicação entre uma aplicação Front-end e um servidor Back-end.

## Conteúdos abordados

- Introdução ao Node.js
- Express.js
- Criação de servidor
- Criação de rotas
- Requisições HTTP
- Método GET
- Respostas em JSON
- Endpoints
- Comunicação entre Front-end e Back-end
- Execução de uma API localmente
