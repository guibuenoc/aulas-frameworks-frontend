# Aula 03 - Frameworks Front-end

## Introdução

Nesta aula foram apresentados alguns dos principais frameworks e bibliotecas utilizados atualmente no desenvolvimento Front-end. Também foram desenvolvidos projetos para entender melhor as diferenças entre cada tecnologia.

## Conteúdos abordados

- Conceito de frameworks Front-end
- React
- Vue.js
- Angular
- Next.js
- Componentização
- Estrutura de projetos
- Organização do código
- Execução de aplicações
- Comparação entre diferentes frameworks

## Tecnologias utilizadas

Durante as atividades foram utilizadas diferentes tecnologias, como:

- React
- Vue.js
- Angular
- Next.js
- JavaScript
- TypeScript
- Node.js
- NPM

## Objetivo da aula

Conhecer diferentes frameworks Front-end e entender como cada tecnologia organiza e desenvolve aplicações web modernas.
