## 📖 Conteúdo das Aulas

### 📘 Aula 01 — Apresentação da Disciplina

Introdução à disciplina de Frameworks Front-end, apresentação dos conteúdos que serão estudados durante o semestre e revisão dos principais conceitos relacionados ao desenvolvimento web.

### ⚙️ Aula 02 — Configuração do Ambiente

Preparação do ambiente de desenvolvimento e configuração das principais ferramentas utilizadas durante a disciplina, incluindo:

- Visual Studio Code
- Node.js
- NPM
- Git
- GitHub
- Terminal
- Organização de projetos

### 🧩 Aula 03 — Frameworks Front-end

Introdução e desenvolvimento de aplicações utilizando alguns dos principais frameworks e bibliotecas do desenvolvimento web moderno.

Tecnologias trabalhadas:

- React
- Vue.js
- Angular
- Next.js
- JavaScript
- TypeScript

### 🌐 Aula 04 — Consumindo APIs

Estudo da comunicação entre aplicações Front-end e APIs.

Principais conceitos:

- APIs
- Requisições HTTP
- Método GET
- JSON
- Fetch API
- Consumo de dados externos
- Manipulação de respostas
- Tratamento de erros

### 🔌 Aula 05 — Criando APIs

Introdução ao desenvolvimento Back-end para compreender como os dados utilizados pelo Front-end são disponibilizados.

Principais conceitos:

- Node.js
- Express.js
- Servidores
- Rotas
- Endpoints
- Requisições HTTP
- Respostas JSON
- Integração entre Front-end e Back-end

### 📐 Aula 06 — Projetos Front-End

Introdução à gestão de projetos Front-end, abordando como transformar uma ideia em requisitos, tarefas e entregas, com aplicação dos conceitos ao Projeto Integrador Interdisciplinar.

Principais conceitos:

- Gestão de projetos Front-end
- Gestão de requisitos
- Requisitos, histórias de usuário e tarefas
- Gestão do backlog
- Priorização e estimativa
- Definition of Done (DoD)
- Scrum e Sprints

### 🎨 Aula 07 — Frameworks CSS

Estudo do CSS para controle de layout e aparência das páginas, seguido da apresentação de frameworks CSS, com foco no Tailwind CSS e na abordagem utility-first.

Principais conceitos:

- Estrutura do CSS (seletor, propriedade e valor)
- Box model
- Flexbox
- Layouts responsivos
- O que é um framework CSS
- Tailwind CSS e abordagem utility-first
- Instalação do Tailwind (Play CDN e Tailwind CLI)

### ⚛️ Aula 08 — Projeto React

Revisão de JavaScript e introdução ao React para construção de interfaces por meio de componentes.

Principais conceitos:

- Revisão de JavaScript
- Manipulação do DOM
- DOM e Virtual DOM
- JSX
- Componentes
- Props
- Listas e keys
- Renderização condicional

### 🔁 Aula 09 — Projeto React 02

Aprofundamento no React, com estado, formulários, efeitos, consumo de APIs e navegação entre páginas.

Principais conceitos:

- State e `useState`
- Formulários e campos controlados
- Eventos `onChange` e `onSubmit`
- `useEffect` e dependências
- Consumo de APIs com `fetch`
- Requisições `GET` e `POST`
- React Router (`BrowserRouter`, `Routes`, `Route` e `Link`)
- Parâmetros de rota com `useParams()`
