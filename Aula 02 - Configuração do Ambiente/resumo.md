# Aula 02 - Configuração do Ambiente

## Introdução

Nesta aula foi feita a preparação do ambiente de desenvolvimento que será utilizado durante a disciplina. O objetivo foi deixar todas as ferramentas instaladas e configuradas para começar a desenvolver os projetos Front-end.

## Conteúdos abordados

- Instalação do Visual Studio Code
- Instalação do Node.js
- Utilização do terminal
- Introdução ao NPM
- Criação e organização de projetos
- Git e GitHub
- Estrutura de pastas e arquivos
- Execução de projetos localmente

## Objetivo da aula

Preparar o ambiente de desenvolvimento e entender as principais ferramentas utilizadas durante a criação dos projetos Front-end.
