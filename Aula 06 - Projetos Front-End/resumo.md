# Aula 06 - Projetos Front-End

## Introdução

Nesta aula foi estudado como organizar um projeto Front-End do início ao fim. A ideia principal foi entender como transformar uma ideia em requisitos, tarefas e entregas, usando conceitos de gestão ágil como backlog, priorização, estimativa, Definition of Done e Scrum.

## Conteúdos abordados

- Por que gerenciar um projeto Front-End
- Gestão de projetos Front-End
- Gestão de requisitos
- Requisito, história de usuário e tarefa
- Gestão do backlog
- Priorização e estimativa
- Definition of Done (DoD)
- Scrum e Sprints
- Organização do trabalho em equipe

## Exemplo de funcionamento

O fluxo estudado durante a aula pode ser representado da seguinte forma:

Requisito → História de usuário → Tarefas → Desenvolvimento → Definition of Done → Entrega

Um requisito como "o sistema deve permitir o gerenciamento de tarefas" pode ser transformado na história "Como usuário, quero criar uma tarefa." e depois quebrado em tarefas como criar formulário, criar componente, validar campos, integrar API e criar testes.

## Objetivo da aula

Entender como planejar e gerenciar um projeto Front-End, organizando requisitos, backlog e entregas para que o trabalho da equipe seja contínuo e alinhado aos objetivos do projeto.
