# Aula 04 - Consumindo APIs no Front-end

## Introdução

Nesta aula foi estudado como uma aplicação Front-end consegue se comunicar com uma API para buscar e apresentar informações ao usuário.

A ideia principal foi entender como os dados podem ser enviados por um servidor e utilizados dentro de uma aplicação web.

## Conteúdos abordados

- Conceito de API
- Comunicação entre Front-end e Back-end
- Requisições HTTP
- Método GET
- Formato JSON
- Fetch API
- Consumo de dados externos
- Manipulação das respostas da API
- Exibição dos dados na interface
- Tratamento básico de erros

## Exemplo de fluxo

O funcionamento básico estudado durante a aula pode ser representado da seguinte forma:

Front-end → Requisição → API → Resposta em JSON → Front-end

A aplicação realiza uma requisição para uma API, recebe os dados e utiliza essas informações para atualizar a interface apresentada ao usuário.

## Objetivo da aula

Entender como consumir APIs no Front-end e utilizar dados externos dentro de uma aplicação web.
